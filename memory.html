📖 まず読む：メモリ交換の手順

メモリ交換の手順（ノート/デスクトップ）

このページの図解とあわせて、手順をテキストでもまとめました。はじめてでも、この通りに進めれば大丈夫です。

共通の準備（安全のために必ず）

  1. 電源を完全に切る。ノートはACアダプタとバッテリーを外す。デスクトップは電源ケーブルを抜く。
  2. 数分置いて放電させてから作業する。
  3. 金属部分（ドアノブや水道の蛇口など）に触れて、体にたまった静電気を逃がす。
  4. メモリは金色の端子とチップに素手で触れず、基板の左右の端だけを持つ。
  5. 通電したまま（電源が入ったまま）の抜き差しは絶対にしない。

ノートPCの場合

  1. 底面のネジを外してカバーを開ける。メモリ専用の小フタがある機種と、底面全体を外す機種があります。
  2. メモリは左右の金具で斜めに固定されています。交換するときは左右の金具を外側に開くと、メモリが斜めに起き上がるので、まっすぐ引き抜く。
  3. 取り付けは、切り欠き（ノッチ）の位置をスロットに合わせ、斜め約30度で奥までしっかり挿す。
  4. メモリを下に倒し、左右の金具が「カチッ」と掛かるまで押す。
  5. カバーを戻してネジを締め、電源を入れる。容量が増えていれば成功です。

デスクトップの場合

  1. ケースの側面パネル（多くは左側）のネジを外して開ける。
  2. マザーボード上の細長いメモリスロットを確認する。
  3. 交換するときは、スロット両端（または片端）のレバーを外側に倒すとメモリが浮くので、まっすぐ上に抜く。
  4. 取り付けは、切り欠き（ノッチ）の位置を合わせ、両端のレバーが「カチッ」と立ち上がって閉じるまで、スロットに対してまっすぐ左右均等に押し込む。
  5. 2枚挿すときは、マザーボードの説明書が指定する同じ色のスロットに挿すと、デュアルチャネルで効率が上がります。
  6. パネルを戻して電源を入れ、容量を確認する。

容量が増えたかの確認（Windows）

タスクバーを右クリックして「タスクマネージャー」→「パフォーマンス」→「メモリ」で、合計容量を確認できます。

① まず知る：なぜ重い?

その重さ、故障じゃなくメモリ不足かも

クルクル回る待ち時間、タブを開くと固まる、Zoom中に他のアプリが動かない。どれもメモリが足りていないサインです。数千円の増設で直ることが多いんです。

② 選ぶ：どのメモリが合う?

メモリは「形」と「世代」で選ぶ

誤購入のいちばんの原因が規格ミスです。DDR3とDDR4は挿さりません。ノート用は短いSO-DIMM、デスクトップ用は長いUDIMM。難しい言葉はペンギンが翻訳します。

分からなくても大丈夫。機種名や型番をメルカリのメッセージで送っていただければ、適合メモリを無料でお調べします。

③ 自分で確認：今のメモリを見る

増設の前に、自分のPCをのぞいてみよう

タスクマネージャー(Ctrl+Shift+Escで起動)の「パフォーマンス」から「メモリ」を開くと、今の容量・空きスロット・速度がひと目で分かります。結果をメルカリのコメントに貼れば、増設か差し替えかペンギンが判定します。

④ 付ける：デスクトップ編

デスクトップは、たった3ステップ

電源を抜く、静電気を逃がす、「カチッ」と挿す。BIOS設定はいじらなくて大丈夫。所要5分です。

⑤ 付ける：ノート編

ノートも、裏蓋1枚とドライバー1本

底面パネルを開けてSO-DIMMを交換するだけ。所要10分から15分。初めてでも、ペンギンが手順に伴走します。

⑥ ノートに挑戦：失敗しない準備

ノートのメモリ交換、準備さえ整えば怖くない

増設できる機種かの確認、必要な道具、WEBでの調べ方、互換チェック、静電気対策、挿し方のコツ。事前に押さえておけば、初めてのノート交換も失敗しません。

⑦ 安心：なぜペンギンか

検査済 + 保証 + 届いてからもサポート

出荷前にMemTest86 Pro全項目をパスしたメモリだけをお届けします。万一の初期不良は7日間保証で交換。

⑧ 深掘り：ブランドとTier

メモリにも「信頼ブランド」があります

チップを作る「御三家」(Samsung/SK hynix/Micron)をはじめ、メモリには品質の格付け(Tier)があります。ペンギンは型番もチップも確認し、信頼できるものだけを出品します。

⑨ ペンギンと一緒に

はじめての増設も、ひとりじゃない

相談から、装着、保証まで。困ったらコメント欄でペンギンが待っています。安心の3ステップで、あなたのPCをよみがえらせます。
