2. デスクトップ環境の基本操作

デスクトップの構成要素

  • デスクトップ: 壁紙、アイコン、右クリックメニュー
  • パネル: 画面下部のタスクバー（アプリランチャー、時計、システムトレイ）
  • ウィンドウマネージャー: ウィンドウの配置・装飾・操作

壁紙の変更

  1. デスクトップ上で右クリック →「デスクトップの設定」
  2. 「背景」タブで壁紙画像を選択
  3. スタイル（拡大、タイル、中央など）を選択

デスクトップの右クリックメニュー

デスクトップ上で右クリックするとアプリケーションメニューが表示されます。中クリック（ホイールクリック）すると、実行中のウィンドウ一覧が表示されます。

3. パネル（タスクバー）の操作

パネルはアプリケーションランチャー、ウィンドウボタン、ワークスペース切替、システムトレイなどを配置するバーです。

アイテムの追加

パネルの空きスペースを右クリック →「パネル」→「パネルのアイテムの追加」

パネルの設定変更

パネルを右クリック →「パネル」→「パネルの設定」で、位置（上/下/左/右）、長さ、透明度などを変更できます。

8. 日本語入力（Fcitx5 + Mozc）

ペンギンコンピュータのPCは日本語入力をセットアップ済みです。Fcitx5とMozc（Google日本語入力のオープンソース版）がインストールされています。

日本語 / 英語の切り替え

操作方法
日本語 ⇄ 英語 切り替え半角/全角 キー、または Ctrl+Space
ひらがな → カタカナ変換F7（全角カタカナ）/ F8（半角カタカナ）
ひらがな → 英数変換F10（半角英数）/ F9（全角英数）
パネル右下のキーボードアイコン（「あ」/「A」）をクリックしても切り替えできます。

入力モードの確認

  • パネルのシステムトレイに「あ」と表示 → 日本語入力モード
  • 「A」と表示 → 英語入力モード

Fcitx5の設定

メニュー →「設定」→「Fcitx5設定」、またはシステムトレイのキーボードアイコンを右クリック →「設定」で開きます。

  • 入力メソッド: 使用する入力メソッドの追加・削除・順序変更
  • 全体の設定: 切り替えキーの変更、候補ウィンドウの表示設定
  • アドオン: クリップボード履歴、クイック入力などの追加機能

日本語入力ができない場合

# Fcitx5が起動しているか確認 pgrep fcitx5 # 起動していない場合は起動 fcitx5 & # インストールされているか確認 dpkg -l | grep fcitx5-mozc
再起動しても日本語入力ができない場合は、ペンギンコンピュータまでご連絡ください。

10. ファイル検索（Catfish）

起動: メニュー →「アクセサリ」→「Catfish」

  1. 検索バーにファイル名やキーワードを入力
  2. 検索場所のフォルダをドロップダウンから選択
  3. Enterキーまたは検索ボタンをクリック

フィルターボタンでファイルタイプ（ドキュメント、画像、音楽等）や日時で絞り込みできます。

11. アーカイブ（圧縮・展開）

ZIP、TAR.GZ、7Z、RAR等の圧縮ファイルに対応しています。

展開

アーカイブファイルをダブルクリック、または右クリック →「ここに展開」。

圧縮

  1. Thunarで圧縮したいファイルを選択
  2. 右クリック →「アーカイブの作成」
  3. ファイル名と圧縮形式を選択して「作成」

21. アップデート

起動: パネルのシールドアイコンをクリック / メニュー →「システム管理」→「アップデートマネージャー」

  1. 「更新を確認」ボタンでリストを更新
  2. 適用したいアップデートにチェック（デフォルトで全選択）
  3. 「アップデートをインストール」をクリック
  4. パスワードを入力
種類説明
セキュリティアップデート脆弱性の修正パッチ
ソフトウェアアップデートバグ修正・機能改善
カーネルアップデートLinuxカーネルの新バージョン
アップデートは定期的に実行してください。セキュリティを最新に保つことが重要です。

22. システムスナップショット（Timeshift）

起動: メニュー →「システム管理」→「Timeshift」

システムの状態をバックアップし、問題発生時に以前の状態に復元できます。

初期設定

  1. 初回起動時にウィザードが表示される
  2. スナップショットタイプを選択（RSYNC推奨）
  3. 保存先ドライブを選択
  4. 自動スナップショットのスケジュールを設定

スナップショットの作成

「作成」ボタンをクリック。数分〜数十分で完了します。

復元

復元したいスナップショットを選択 →「復元」→ 確認して実行 → 再起動。

大きなアップデートの前にスナップショットを作成しておくと安心です。個人データ（ホームディレクトリ）はスナップショットに含まれません。

  • 電源ボタンの動作（シャットダウン、サスペンド等）

25. ネットワーク設定

Wi-Fi接続

  1. パネルのネットワークアイコンをクリック
  2. 利用可能なWi-Fi一覧から選択
  3. パスワード（セキュリティキー）を入力して「接続」

有線接続

イーサネットケーブルを接続すると自動的に接続されます。

固定IPアドレスの設定

ネットワークアイコンを右クリック →「接続を編集する」→ 対象の接続を選択 →「IPv4設定」タブでメソッドを「手動」に変更。

26. Bluetooth

デバイスのペアリング

  1. システムトレイのBluetoothアイコンをクリック
  2. 「検索」をクリックして近くのデバイスを探索
  3. デバイスを選択して「ペアリング」
  4. 必要に応じてPINコードを確認

Bluetoothのオン / オフ

システムトレイのBluetoothアイコンを右クリック →「Bluetoothをオフにする」/「オンにする」。

27. プリンター

Linux Mint 21以降ではIPP（Internet Printing Protocol）によるドライバーレス印刷が標準サポートされています。対応プリンターは自動検出されます。

印刷方法

アプリケーションのメニューから「ファイル」→「印刷」を選択します。

メーカー別ドライバー

メーカー方法
HP標準搭載済み。GUIツール: sudo apt install hplip-gui

28. 音声設定

Linux Mint 22以降ではPipewireが標準のサウンドサーバーです。

  • スピーカーアイコンを右クリック →「音量の設定」で出力デバイスを選択
  • アプリケーション別の音量制御も可能

30. ブートメニュー（Grub）

Grubは起動時のOS選択メニューです。起動中に左 Shift キーを押し続けると表示されます。

カーネルの選択

Grubメニュー →「Advanced options」から使用するカーネルを選択できます。問題が起きた場合に以前のカーネルで起動できます。

常にGrubメニューを表示する設定

# /etc/default/grub.d/90_custom.cfgに追記 GRUB_TIMEOUT="5" GRUB_TIMEOUT_STYLE="menu" # 反映 sudo update-grub

31. システムアップグレード

タイプ例所要時間
マイナー22.1 → 22.3短時間
メジャー21.3 → 22数時間
メジャーアップグレードは直接スキップできません（例: 21 → 22は不可）。必ず21 → 21.3 → 22の順にアップグレードしてください。

32. Flatpak

Linux MintではFlatpakがデフォルトでサポートされており、Flathubリポジトリが有効です。ソフトウェアマネージャーからもFlatpakアプリをインストールできます。

# アプリの検索 flatpak searchアプリ名 # インストール flatpak install flathubアプリケーションID # アップデート flatpak update # 不要なランタイムの削除 flatpak uninstall --unused

33. トラブルシューティング

起動時のフリーズ

  1. Grubメニューで「Compatibility Mode」を選択して起動
  2. 起動後、ドライバーマネージャーでプロプライエタリドライバーをインストール
  3. 再起動

音が出ない

まずサウンドサーバーを確認します。

inxi -A

Pipewireで音が出ない場合はPulseAudioに戻せます。

sudo apt purge pipewire pipewire-bin systemctl enable --user pulseaudio sudo reboot

パスワードを忘れた場合

  1. Grubメニュー →「Advanced options」→「Recovery mode」
  2. リカバリーメニューで「root」を選択
  3. passwd ユーザー名 でパスワード再設定
  4. reboot で再起動

# クリックしたウィンドウを強制終了 xkill # またはCtrl+Alt+Escape # コマンドラインで終了 kill PID番号 killallプロセス名

ログの確認

journalctl -xe # システムログ journalctl -b # 起動時のログ dmesg | tail -50 # カーネルメッセージ
