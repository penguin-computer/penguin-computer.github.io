🐧 Penguin Computer

自分たちの自由なコンピュータ（Your own computer）

バージョンアップのたびにパソコンを買い替えるのは、もうやめよう。

Windows 10のサポートは2025年10月に終了しました。Windows 11は古いパソコンにインストールできないことが多く、買い替えを迫られます。

でも、まだ使えるパソコンを捨てる必要はありません。メモリ増設・SSD換装・Linux化で、今あるパソコンはまだまだ快適に使えます。

今、パソコンもメモリも高い

半導体価格の高騰により、パソコン本体もメモリも値上がりが続いています。

  • 新しいパソコンに買い替える予算がない
  • メモリの増設も部品が高い
  • Windows 11にアップデート出来ない
  • まだ動くパソコンを捨てるのはもったいない

お金をかけすぎずに、今あるパソコンを活かす方法があります。

ペンギンができること

① 検査済みメモリの販売
MemTest86 Proで1枚ずつ検品。メルカリにて、機種相談・7日初期不良保証つきでお届け。
② 宅配アップグレード
お使いのパソコンをお送りいただき、メモリ増設・SSD換装・Linux化を承ります。

🚚 宅配アップグレードサービス

お手元のパソコンを宅配でお預かりし、作業後にお返しします（全国対応）。

🧩 メモリ増設
検査済みメモリを増設し、動作のもたつき・フリーズを軽減します。増設後に二次検品してからご返送します。
💾 SSD換装（データクローン）
HDDからSSDへ交換すると、起動やアプリの動作が大幅に速くなります。今お使いの環境（データ）をそのまま新しいSSDへクローンします。※データの内容・完全性は保証いたしません。事前のバックアップをお願いします。
🐧 Linux化（おすすめ）
Windows 10終了機の延命に。当方は「インターネットのプライバシー」を大切にする立場から、軽快で安全なLinux（Linux Mint Xfceを標準）への移行を積極的におすすめしています。考え方はbooksもご覧ください。
🔍 動作診断（送料のみご負担）
パソコンの状態を診断し、最適なアップグレードをご提案します。診断の際には、内部やキーボード周りのクリーニング（ブロア・エアダスター等）を必ず行います。アップグレードをご依頼いただかない場合でも、この清掃は実施しますので、それだけでもお使いのパソコンが快適になります。

料金について

作業料金は内容により異なり、部品相場も変動するため、お見積り制としています（固定価格は掲載していません）。

概算の目安：

  • 動作診断：無料（往復送料はお客様ご負担）
